# Homework 2: 88-Key Polyphonic Piano & FIFO Sequencer

React piano application for MIDI notes 21–108 (A0–C8) with an eight-voice Web Audio oscillator demo and FIFO sequence recording/replay.

## Run locally

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm test
npm run build
```

The sound is a synthesized oscillator demo, not recovered Legacy piano audio. See `TASK_DECOMPOSITION.md` for requirements and verification evidence.
